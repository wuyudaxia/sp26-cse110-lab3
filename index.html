Unfinished Business

However, Yu Wu mentioned that everyone should have Java Edition installed and updated before the next session.

New Business

Server Setup Proposals

The team discussed several key decisions for the server:

  • Run on Minecraft 1.21.5 with Paper as the server software
  • Set the world border to 10,000 blocks from spawn
  • Enable hard mode for the survival experience
  • Use a shared resource pack for custom textures

Technical Decisions

Wy UU will set up the server on a dedicated Linux VPS with 8GB RAM to handle up to 20 players.

Wu Wu suggested using CoreProtect for block logging so griefing can be rolled back easily.

Comments, Questions, and Concerns

Note: Keep the plugin list small at launch to avoid lag.

Important: Everyone needs to whitelist their Minecraft username before opening day.

Idea from Yu Yu: Build a massive redstone door at the spawn entrance.

Concern from Wu Wu: If we enable hard mode from day one, new players might ragequit.

A question was raised during the meeting:
Should we allow TNT and fire spread, or disable them to prevent accidental destruction?
